# 運営者の承認の置き場

**ここに置くのは、運営者本人だけ。** AI（Claude）も、毎朝の自動実行も、ここには書かない。

取得元の判定カード（`data/ref/torimoto-card.json`）1枚につき、承認のファイル1つ。
ファイル名はカードの名前（例：`kobai-nta-home.json`）。

```json
{
 "カード": "kobai-nta-home",
 "運営者承認": "承認",
 "承認したカード版": 1,
 "承認時カード指紋": "（data/ref/card-ichiran.md に出ている64文字）",
 "承認日": "2026-09-25"
}
```

## この承認が数えられる条件（`common/kado.py` が毎回確かめる）

- カードの「統括判定案」が「取ってよい」で、必要な欄が全部埋まっている
- 「承認したカード版」と「承認時カード指紋」が、**いまのカード**と一致する
  （承認のあとでカードが1文字でも変わったら、承認は効かなくなる。もう一度承認する）
- このファイルを入れた保存（commit）に、**AI の印**（`Co-Authored-By: Claude` など）が無い
- このファイルを入れた保存が、**自動実行（bot）**のものではない
- 保存したあとで書き換えられていない

どれか1つでも欠けたら、その取得元は「取ってよい」にならず、取りに行かない。

## 限界

AI も運営者と同じ GitHub の鍵で動いている。**AI の印を付けずに保存されたもの**は、
機械では見分けられない。ここで止められるのは、ふだんの手順で AI や自動実行が
書いてしまった承認まで。AI は、このフォルダに書かないことを決まりにしている。
