# 突合率

県警CSVの住所を町丁目の区画に突き合わせた結果。
CLAUDE.md 8節の判断基準は「1%未満」。

出すのは**割合**と、**数えなかったものの理由ごとの全体合計**。
市ごと・手口ごと・年ごとの行数は出さない（共通仕様3.2）。
突き合わせできなかった行そのものは、理由つきで金庫に残している。

## 数えなかったもの（`index.json` の `not_counted`）

| 箱 | 件数 | 中身 |
|---|---:|---|
| `unresolved` | 1 | 町丁目は読めたが、境界データに該当が無い |
| `unobserved` | 9 | 町丁目の欄が空 |
| `undecided` | 19 | 町丁目は読めたが、どの区画か決まらない（丁目の記載が無い・親と丁目が併存） |
| `gone` | 0 | 消えた町丁目 |

**4つとも出している。0でも出す。** 欠けている鍵は0ではない。
