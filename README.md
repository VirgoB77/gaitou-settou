# 街頭窃盗統計

兵庫県（尼崎市・西宮市）の町丁目別 窃盗認知件数。
<https://gaitou-settou.com>

住まいを探している人のために作りました。
件数と人口千人あたりの件数を、そのまま並べて出します。
評価や点数はつけません。判断の材料を出すところまでが役割です。

いま載せているのは兵庫県の尼崎市・西宮市、2018〜2025年の8年分です。

## 何を載せているか

窃盗の7手口（自転車盗・車上ねらい・部品ねらい・自動車盗・オートバイ盗・
自動販売機ねらい・ひったくり）の認知件数。

町丁目には2つの層にまとめて出します。手口を1つずつ町丁目に割ると、
ほとんどの町丁目が「1-2」になり、地図として読めなくなるためです。

- **自転車**（自転車盗）
- **車・バイク**（車上ねらい・部品ねらい・自動車盗・オートバイ盗）

自動販売機ねらい・ひったくりは、件数が少ないため町丁目には出していません。
市ごと・年ごとの件数は、姉妹サイト横断用の `index.json` に入れています
（地図やページには出していません）。**こちらの判断で外しています。**
データが無いわけではありません。

載せていないもの、その理由、訂正・削除の申し出先は
[掲載方針](https://gaitou-settou.com/policy.html)に書いています。

## 小さい数の扱い

件数が1〜2件の升は実数を出しません。1件は統計というより個々の出来事に近く、
小さな町丁目ではそれが誰のことかに結びつきうるためです。

合計は出しません。合計と内訳を並べると、引き算で伏せた升が分かるためです。
町丁目には年ごとの数字も時間帯も出しません。どちらも別の分割になり、
足し合わせると引き算の相手になります。

この決まりは姉妹サイトと共通で、
[共通仕様](https://github.com/VirgoB77/ogataten-nippo/blob/main/docs/kyotsu-shiyo.md)
に1か所でまとめています。

## 出典

- 犯罪認知件数：兵庫県警察（兵庫県 オープンデータ）
- 町丁目境界・人口：e-Stat 令和2年国勢調査 小地域
- 背景地図：国土地理院タイル

いずれも公開されているデータを加工して表示しています。
元データそのものへのご意見は、各配布元へお願いします。

## 作り

静的サイトです。サーバーサイドの処理を持ちません。
生成済みの JSON と GeoJSON だけを読み、実行時に CSV を解析しません。

```
common/    住所の正規化と、小さい数の伏せ方（姉妹サイトと共通）
scripts/   データの取得・整形・ページ生成（Python 標準ライブラリ）
tests/     出力そのものを見張る検査
data/build 生成済みの GeoJSON
cho/       町丁目ごとのページ
```

検査は3本あります。どれか1つでも落ちたら公開しません。

```
python -m unittest discover -s tests
python scripts/check_small_counts.py    # 伏せた升が引き算で戻らないか
python scripts/check_copy.py            # 地域を評価する言葉が無いか
```

## 運営

鯨屋（くじらや）。大阪府・兵庫県で行政が公開する一次情報を、
消える前に記録しています。連絡先は[掲載方針](https://gaitou-settou.com/policy.html)に。
